# צום לסירוגין ⏱️

אפליקציית ווב פשוטה למעקב אחרי צום לסירוגין. היא בעברית, עובדת כקובץ אחד ולא צריך להתקין אותה.

- פרוטוקולים: 13:11, 14:10, 16:8, 18:6, 20:4, OMAD
- טיימר עם טבעת התקדמות, שעת יעד וזמן שנשאר
- שלבים כלליים בגוף לפי מספר שעות הצום
- התראה כשמגיעים ליעד
- מונה מים יומי
- רצף ימים, ממוצע, גרף שבועי והיסטוריה

כל הנתונים נשמרים רק במכשיר שלך (localStorage). אין שרת ואין חשבון.
